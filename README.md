## GitHub Pages
For a project site:
1. Create a public repository named `rennell-software-masterclass`.
2. Upload all files at the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Open the Pages URL shown by GitHub.

GitHub Pages project sites normally use:
`https://YOUR-GITHUB-USERNAME.github.io/rennell-software-masterclass/`

For stronger branding, consider buying a custom domain such as a suitable Arif Rennell / Rennell Software domain and connecting it to GitHub Pages after the site is live.
